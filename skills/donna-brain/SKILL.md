# Donna Brain — OKF capture & upkeep

## When to Use
- Lutfi tells Donna what he did, wants, feels, plans, or who he met — every turn that carries durable signal.
- Lutfi asks "catat", "ingat", "simpan", "tolong noted", or asks about a person/project/past event.
- A new person, project, organization, goal, commitment, or decision appears in conversation.
- A skill was forged into `.agents/skills/` and needs a `toolbox/` entry.
- Start of a session (`pending` flush) and end of any capture batch (`check`).

## Inputs
- The conversation turn(s) with the new information, plus the channel (`telegram` | `terminal`).
- Existing concepts: search `.okf/` with `grep`/`glob` by name, slug, or tag before creating anything.
- Hindsight results from `xd://recall` for the same entity.

## Output Structure
```
.okf/
  index.md                          # generated root index (okf_version 0.2)
  log.md                            # lifecycle events only
  profile/lutfi.md                  # the principal
  profile/preferences/<slug>.md     # durable rules about how to serve Lutfi
  people/<first>-<last>.md          # everyone around Lutfi
  organizations/<slug>.md
  projects/<slug>.md
  goals/<slug>.md
  commitments/<YYYY-MM-DD>-<slug>.md
  decisions/<YYYY-MM-DD>-<slug>.md
  journal/<YYYY>/<MM>/<YYYY-MM-DD>.md
  persona/donna-paulsen.md          # who Donna is (reference dossier)
  toolbox/<skill-name>.md           # one per skill in .agents/skills/
```
Per-type frontmatter and body skeletons: `references/templates.md`.

## Process
1. **Recall before write.** `xd://recall` the entity/topic and `grep` `.okf/` for its slug or name. Update the existing concept if one exists — never create a near-duplicate.
2. **Journal first.** `python3 .agents/skills/donna-brain/scripts/brain.py today` prints today's journal path (creates it from the template if missing, date in Asia/Jakarta). Append a timestamped bullet (`HH:MM WIB`) under the right heading; link every person/project mentioned.
3. **Promote durable facts** into their own concept (person, project, goal, commitment, decision, preference) using `references/templates.md`. One concept per file; slug = lowercase kebab-case. Cross-link both ways (journal → concept, concept `# Riwayat`/`# Log Kerja` → journal).
4. **Stamp trust.** Set/refresh `generated: { by: donna/<model-id>, at: <UTC ISO> }`. Add a `sources` entry for what Lutfi said (`conversation:<channel>/<date>`, `author: human:lutfi`). Add `verified: { by: human:lutfi }` only when Lutfi confirms the written content.
5. **Retain.** Write one self-contained fact per durable item to `xd://retain` (who, what, when, why + the OKF path in `context`). If retain errors, set `memory_sync: pending` on that concept and keep going.
6. **Lifecycle → log.** Only bundle-level lifecycle events go to `.okf/log.md` (newest date first): concept deprecated/superseded, bulk regeneration, verification pass. Routine edits do not.
7. **Check.** `python3 .agents/skills/donna-brain/scripts/brain.py check` regenerates every `index.md` and runs the OKF validator `--strict`. Fix every error and warning it reports.
8. **Flush pending** at session start: `brain.py pending` lists notes whose retain failed; retain them, then delete the `memory_sync` key.

## Critical Rules
- Never write secrets (passwords, API keys, tokens, OTP, PIN, card numbers) into `.okf/` or Hindsight. Note that a secret exists and where Lutfi keeps it, never its value.
- Never invent facts, dates, or feelings. Unknown → leave the field out or `null`; inferred → prefix the bullet with `[INFERENCE]`.
- Never name a concept `index.md` or `log.md`; never hand-edit `index.md` (it is generated by `brain.py reindex`).
- Never delete a concept about a person or project that ended — set `status: deprecated` and log the deprecation.
- Feelings are recorded factually and kindly, in Lutfi's own words when possible; never diagnose.
- Every `.md` under `.okf/` must carry frontmatter with a non-empty `type`, or the bundle is non-conformant.
